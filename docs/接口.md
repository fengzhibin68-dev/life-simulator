## 2. 运行状态对象（GameState）

```js
{
  version: 1,
  seed: 123456,                 // 本局随机种子
  rngState: 987654321,          // RNG 内部状态，存档要一起存，保证读档后序列一致
  age: 0,
  birth: { place: "县城", family: "温饱", text: "你出生在了县城的温饱家庭。" },  // createGame 按 seed + 起始金钱生成
  origin: "normal",             // normal | rich | poor | custom（只决定起始资源，不附带属性加成）
  talent: "scholar",            // scholar | social | iron | lucky
  attrMode: "alloc",            // alloc | random，仅用于存档与随机人生的揭晓
  attrs:      { intelligence, charm, constitution, eq, will, luck },   // 开局 0~100，运行期无上限（下限 0）
  resources:  { money, health, stress, happiness },                    // 见需求
  tags: [],                     // 字符串数组，如 ["大学生", "已婚"]
  flags: {},                    // 布尔标记，如 { retired: true }
  log: [],                      // [{ age, text, kind }]，kind ∈ event | check | year | life
  usedEvents: {},               // { eventId: 最后一次触发的年龄 }
  eventCounts: {},              // { eventId: 累计触发次数 }，用于权重递减
  currentEventId: null,
  endingId: null,
  goodStreak: 0,                // 连续几年没碰到正面事件
  yearsPlayed: 0
}
```

## 3. 事件（Event）

```jsonc
{
  "id": "event_18_exam",        // 全局唯一，event_<年龄>_<英文名>
  "title": "高考",
  "stage": "teen",              // child | teen | youth | adult | middle | general
  "ageMin": 18,
  "ageMax": 18,
  "weight": 100,                // 抽取权重，>=1
  "cooldown": 99,               // 冷却年数：上次触发后，要再等多少年才可能再出现
  "once": true,                 // true = 一辈子只触发一次
  "forced": true,               // 可选，true = 到年龄必触发（年龄强制事件）
  "auto": false,                // 可选，true = 自动事件：只有 1 个选项，婴幼儿由父母代为处理
  "tone": "neutral",            // good | bad | neutral，用于连续负运气的权重修正
  "conditions": [               // 可选，全部满足才进池
    { "target": "intelligence", "op": ">=", "value": 40 }
  ],
  "text": "你走进考场，{name} 的名字印在准考证上。",   // {name} 会被替换
  "options": [ /* 2~3 个 */ ]
}
```

`conditions[].target` 可取值：6 个属性名 / `health` `money` `stress` `happiness` / `age` / `tag:大学生`
`conditions[].op`：`>=` `<=` `>` `<` `==` `!=`

## 4. 选项（Option）

```jsonc
{
  "text": "全力冲刺",
  "effects": { "stress": 15, "health": -5 },      // 无判定的直接效果，可省略
  "tags": ["拼命"],                                // 可选
  "log": "你决定全力冲刺。",                        // 可选，写进人生日志
  "check": {                                       // 可选，有判定
    "attr": "intelligence",
    "difficulty": 55,
    "success": { "effects": { "happiness": 10 }, "tags": ["大学生"], "log": "你考上了。" },
    "fail":    { "effects": { "stress": 15 },   "tags": ["落榜"],   "log": "你落榜了。" }
  }
}
```

**记法**：`effects` 的 key 只允许 10 个（6 属性 + 4 资源），正数加、负数减，结算后自动夹到合法区间。

## 5. 结局（ending）

`data/endings.json` 只存**文案**；判定逻辑写死在 `src/core.js` 的 `evaluateEnding()`，顺序即优先级：

| 顺序 | id | 条件 |
| --- | --- | --- |
| 1 | `end_early` | `health<=0` 或 `age<60` |
| 2 | `end_lonely` | `happiness<40` 且 tags 无 `已婚` `有子女` `挚友` |
| 3 | `end_career` | `money>=100000` 或有 tag `事业成功` |
| 4 | `end_family` | `happiness>=70` 且有 `已婚` 或 `有子女` |
| 5 | `end_ordinary` | 兜底 |

```jsonc
{ "id": "end_ordinary", "title": "平凡而温暖", "text": "……", "epitaph": "……", "warmText": "……" }
```

## 6. 核心函数（src/core.js）

| 函数 | 作用 |
| --- | --- |
| `createGame(seed, { origin, talent, name, attrs, attrMode, startResources })` | 生成初始状态 |
| `pickEvent(state, events)` | 抽下一个事件，返回 Event 或 `null` |
| `judge(state, check)` | 判定成功率与成败 `{ rate, roll, success }` |
| `resolveOption(state, event, index)` | 执行选项：效果 + 判定 + 日志，返回结果对象 |
| `settleYear(state)` | 年终结算（年龄、健康衰减、压力、金钱） |
| `checkDeath(state)` | 死亡判定，返回 `{ dead, cause }` |
| `evaluateEnding(state)` | 返回结局 id |
| `nextYear(state, events)` | 完整一年：抽事件 → 等玩家选择 |

**约束**：`ui.js` 不许直接改 `attrs` / `resources`，一律走 `resolveOption` / `settleYear`。

### 属性分配（v1.1）

| 名称 | 说明 |
| --- | --- |
| `ATTR_POINT_TOTAL = 300` | 开局可分配总点数 |
| `ATTR_ALLOC_MAX = 100` | 开局单项上限（运行期不适用） |
| `validateAttrs(attrs)` | 返回 `{ ok, spent, remaining, values, errors }`；`values` 已取整并夹到 0~100 |
| `createGame(..., { attrs })` | `attrs` 省略时按全 50 兜底（兼容 `tools/simulate.js` 与旧调用）；**free 加点模式**下总和超过 300 直接抛错，`random` 模式不校验预算 |

- 允许留剩余点数：`remaining >= 0` 即可开局，剩余点数不换算任何资源。
- 运行期 `applyEffects` 对属性**只保留下限 0**，不再夹上限 100。

### 平衡参数（实现细节）

| 规则 | 值 | 为什么 |
| --- | --- | --- |
| 压力每年自然缓解 | `STRESS_RECOVERY = 3` | 不加这条，压力只涨不降，40 岁后常年满压 |
| 60 岁后复用冷却 | `max(cooldown, 8)` | 老年阶段只有中年 + 通用池，冷却太短会刷同一条 |
| 重复事件权重衰减 | `weight / (1 + 次数 × 0.6)` | 见过的事件更难再抽到 |

改这几个值之前先跑 `node tools/simulate.js 500`，对照 [测试记录.md](测试记录.md) 的基线。

## 7. 随机数

`mulberry32` 伪随机，状态存 `state.rngState`。同一 `seed` 必须复现同一局，
`tools/simulate.js` 靠这一点做批量回归。

## 8. 存档

`localStorage` key：`life-sim.save.v1`；值为 `JSON.stringify(GameState)`。
每次玩家做出选择后自动写入；页面加载时若存在存档，直接恢复主游戏页。
