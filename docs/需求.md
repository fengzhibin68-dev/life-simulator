# 需求文档 —— 人生模拟器 MVP

> 本文件是玩法的唯一权威。代码与本文不符时，以本文为准；要改玩法先改本文。
> 原始计划由产品方给出，本文件是它的仓库版本。

## 1. MVP 要实现的体验

玩家创建角色，每年触发一个事件，做 2~3 个选择，属性 / 资源发生变化，人生日志记录关键节点。
角色从 0 岁推进到死亡，**不固定 60 岁结算**；60 岁后继续游戏，死亡时结算多维结局，并可重开。

## 2. 范围边界

| 模块 | MVP 做 | MVP 不做 |
| --- | --- | --- |
| 角色创建 | 6 属性加点（300 点）+ 出身 + 天赋（自选 / 随机） | 捏脸、性格测试 |
| 时间推进 | 1 年 1 回合，0 岁到死亡，硬上限 120 | 月份 / 行动点 |
| 事件 | 41 个，每年 1 个 | 关系网、连锁大剧情 |
| 选择 | 每个事件 2~3 个选项 | 多级对话树 |
| 判定 | 属性 + 运气 + 难度 | 战斗 / 技能 |
| 资源 | 金钱、健康、压力、幸福 | 房产、股票、负债 |
| 关系 | 标签 / 简单好感 | 独立 NPC 系统 |
| 职业 | 标签：学生 / 打工人 / 创业者 | 职级晋升树 |
| 结局 | 5 个，死亡时判定 | 隐藏结局、成就 |
| 存档 | localStorage 自动存档 | 云存档 |
| 美术 | 纯文字 + 简单面板 | 图片 / 动画 |

## 3. 属性与资源

**6 个属性**：开局在 6 项之间自由分配 **300 点**，每项 **0~100**，**允许留剩余点数**（不换算、不惩罚）。

| key | 中文 | 判定用途 |
| --- | --- | --- |
| `intelligence` | 智力 | 学习、考试、技术 |
| `charm` | 魅力 | 社交、恋爱、谈判 |
| `constitution` | 体质 | 健康、抗病、寿命 |
| `eq` | 情商 | 人际、压力处理 |
| `will` | 意志 | 抗压、坚持、戒断 |
| `luck` | 运气 | 随机修正、稀有事件 |

> **0~100 只是开局加点范围**：开局之后属性随事件涨落**不再受上限限制**（下限仍为 0），
> 判定按实际数值计算，成功率最终仍夹在 5%~95%。

**游戏模式**（创建页二选一）：

| 模式 | 属性 | 天赋 | 玩家是否提前看到 |
| --- | --- | --- | --- |
| 自由加点 | 自己分配 300 点 | 4 选 1 | 是 |
| 随机人生 | 每项独立随机 0~100 | 随机 | 否，开局前显示「？？？」，点开始后揭晓 |

**4 个资源**

| key | 中文 | 范围 / 后果 |
| --- | --- | --- |
| `money` | 金钱 | 0 起，无上限；≤0 时幸福 -3 |
| `health` | 健康 | 0~100；≤0 立即死亡 |
| `stress` | 压力 | 0~100；≥80 时健康 -3、幸福 -5 |
| `happiness` | 幸福 | 0~100；影响结局 |

**出身**：三个预设 + 一档「自定义」，只决定**起始金钱 / 压力 / 幸福**，不再附带属性加成。

| 出身 | 起始金钱 | 起始压力 | 起始幸福 |
| --- | --- | --- | --- |
| 普通家庭 | 1000 | 0 | 50 |
| 富裕家庭 | 6000 | 10 | 50 |
| 困难家庭 | 0 | 0 | 50 |
| 自定义 | 玩家填 0~100000 | 玩家填 0~50 | 玩家填 0~100 |

**出生描述**：开局根据起始金钱生成一句话——「你出生在了〈农村 / 县城 / 三线城市 / 二线城市 / 一线城市〉的〈贫困 / 温饱 / 小康 / 富裕 / 优渥〉家庭。」
地点在同一财富档位内随机（越有钱越可能在大城市），家庭档位由起始金钱决定；这句话显示在游戏页顶部，并作为第一条人生日志。

**天赋**：自由加点模式下 4 选 1，随机人生模式下随机且开局前不可见。
读书料（学习判定 +8）/ 社交达人（社交判定 +8）/ 铁打身体（健康损失减半）/ 锦鲤（判定时运气 +10）

## 4. 事件

共 **41 个**事件，按人生阶段分配；60 岁后不新增事件卡，改用「中年 + 通用」池，靠冷却和权重修正减少重复感。

| 阶段 | 年龄 | 数量 |
| --- | --- | --- |
| 童年 | 1~12 | 9 |
| 少年 | 13~18 | 8 |
| 青年 | 19~25 | 9 |
| 成年 | 26~40 | 6 |
| 中年 | 41~60 | 5 |
| 通用 | 全年龄 | 4 |

**1~6 岁是自动事件**：婴幼儿生病时没有选择权，由父母代为处理（`auto: true`），事件只有一句结果。
目前是「半夜发烧」「上吐下泻」两个，冷却 3~4 年，避免年年生病。

**年龄必须和内容对得上**：涉及上学、请假、工作、结婚、生育、买房等前提的事件，年龄下限要符合现实。
例如「请几天假」类选项不能出现在儿童期，彩票类事件不早于 18 岁，交通事故类不早于 8 岁。
孩子的相关事件要求玩家已有「有子女」标签。

字段定义见 [接口.md](接口.md)。触发规则：

1. 年龄强制事件优先（如 18 岁高考）。
2. 否则从满足条件的事件池按权重抽 1 个。
3. 同一事件冷却 3 年；关键事件只触发一次。
4. 连续 3 年没有正面事件时，提高正面事件权重。
5. 60 岁后继续从中年 + 通用池抽取，不强制结算。

## 5. 判定

```
成功率 = 50% + (属性 - 50) × 0.6% + (运气 - 50) × 0.2% - 难度修正
```

- 限制在 **5% ~ 95%**
- 难度修正 = `(difficulty - 50) × 1%`（difficulty 取值 10~90）
- MVP 只做成功 / 失败；大成功、大失败留到 v0.2

## 6. 每年结算

1. 年龄 +1
2. 健康随年龄分档下降：30 岁后 -1 / 50 岁后 -2 / 70 岁后 -3 / 85 岁后 -5
3. 压力 ≥80：健康 -3、幸福 -5
4. 金钱 ≤0：幸福 -3
5. 记录人生日志

## 7. 死亡判定

1. 健康 ≤0：立即死亡
2. 60 岁后每年判定一次死亡风险：

| 年龄 | 每年基础死亡概率 |
| --- | --- |
| 60~69 | 1% |
| 70~79 | 3% |
| 80~89 | 7% |
| 90~99 | 12% |
| 100~109 | 20% |
| 110~119 | 30% |
| 120 | 强制死亡 |

健康修正：健康 <50 时 +2%，健康 <25 时 +5%（累加）。

60 岁后不强制结算，只有死亡才进入结局页。

## 8. 结局（死亡时判定，按优先级）

| 优先级 | 结局 | 条件 |
| --- | --- | --- |
| 1 | 早逝 | 健康 ≤0 死亡，或死亡年龄 <60 |
| 2 | 孤独终老 | 死亡时幸福 <40，且无「已婚 / 有子女 / 挚友」标签 |
| 3 | 事业有成 | 死亡时金钱 ≥100000，或有「事业成功」标签 |
| 4 | 家庭美满 | 死亡时幸福 ≥70，且有「已婚 / 有子女」标签 |
| 5 | 平凡而温暖 | 以上均不满足；幸福 ≥60 时文案更温暖 |

结局页展示：结局标题、死亡年龄、职业标签、金钱 / 健康 / 幸福、3 条人生高光、一句墓志铭、重开按钮。

## 9. 技术方案

纯 HTML + CSS + 原生 JS；事件数据 `data/events.json`；状态存 `localStorage`；无后端、无数据库、无构建步骤。

页面：开始页 → 角色创建页 → 主游戏页（顶部年龄 / 左侧属性 / 中间事件 / 底部日志）→ 结局页。

## 10. 验收标准

1. 能创建角色并开始人生
2. 每年自动推进，触发 1 个事件
3. 每个事件 2~3 个选项，选择后数值变化可见
4. 属性判定有成功 / 失败反馈
5. 人生日志记录至少 5 类关键事件
6. 健康归零或年龄分档死亡判定触发结局；60 岁后仍可继续
7. 5 个结局至少各能触发一次
8. 刷新页面能继续游戏
9. 一局 5~15 分钟，长寿局允许略长
10. 重开后事件不会连续大量重复
11. 创建页可自由分配 300 点（可留剩余），每项 0~100
12. 随机人生模式开局前看不到属性与天赋，开始后正常显示

## 11. 待确认

| # | 问题 | 现状 |

| Q1 | 事件总数：计划正文写 20~25，但阶段表相加是 28 | MVP 按 25 实现（童年 4 / 少年 5 / 青年 5 / 成年 4 / 中年 4 / 通用 3） |
| Q2 | 结局优先级按表内顺序，意味着"有钱但孤独"会判成孤独终老、"又有钱又顾家"判成事业有成 | 按表内顺序实现，待确认是否符合预期 |
| Q3 | 压力只涨不降会让玩家 40 岁后常年满压，每年白扣健康 | 已加「每年压力 -3」的缓解（`STRESS_RECOVERY`），属于原需求没有的机制，**需确认** |

| Q5 | 「事业成功」标签来自晋升事件，可重复触发时几乎必得 | 已改为晋升只发生一次、难度 55→62，缓解后仍占约 15% |
